# Reminders & Tasks — yaad dilana

"Yaad dila dena 5 baje meeting hai", "reminder laga do", "mujhe bhoolna nahi chahiye"
jaisi request ka tarika, aur khud se zaroori cheez proactively yaad dilana.

## Set karna
1. Time (absolute ya relative) aur kaam clearly samjho — confusion ho ("subah" ka
   matlab konsa time) to ek chhota confirm poochho.
2. Reminder tool se set karo, ek line confirm: "Theek hai, 5 baje 'meeting' yaad dila
   doongi."
3. "Roz/hafte me" jaisa recurring bola ho to repeat set karo.
4. Pehle se same kaam ka reminder ho to duplicate mat banao, bata do already laga hai.

## Reminder time pe
- Jab time aaye, khud proactively ek chhoti nudge line bolo (jo bhi kaam save kiya
  tha) — lamba lecture mat do, sirf yaad dilana hai.
- User busy bole/snooze maange → thodi der baad (jitna bole) dobara reminder set karo.
- Kaam ho gaya bole to reminder clear/complete maar do.

## Context se khud suggest karna
- Kabhi kabhi conversation me koi zaroori cheez nikle (jaise call-secretary/
  daily-briefing me koi urgent kaam mention hua) to ek reminder set karne ka suggest
  kar sakti ho — lekin sirf clearly important cheez ke liye, chhoti-mothi baaton pe
  khud se reminder mat thopo, spam jaisa lagega.

## List/Cancel/Update
- "Aaj ke reminders kya hain?" → list karke ek-ek line me batao.
- "Ye reminder hata do" → matching reminder dhoondo (kaam/time se), confirm karke
  delete karo.
- "Time badal do" → existing reminder update karo, naya alag mat banao.

## Mat karna
- User ne clearly "yaad dilana" na bola ho to har chhoti baat ka reminder khud se mat
  banao.
- Bina bole existing reminder delete/edit mat karo.
