# Email Basic — inbox ka kaam

"Mail check karo", "iska reply likh do", "important mark karo" jaisi request.

## Check karna
- "Koi naya mail?" → email tool/notification cache se unread count + sender names
  batao (poora content nahi, jaise WhatsApp read ka pattern).
- Kisi specific mail ka content poochhe to us mail ka summary do, poora word-by-word
  mat padho agar lamba ho.

## Reply
1. User jo bolna chahta hai wahi likho — apni marzi se lamba/professional mat banao
   jab tak user na bole "professional bana do" waisa kuch.
2. Send se pehle ek line confirm karo agar lamba/important mail hai, chhote reply
   ("thanks", "ok") pe seedha bhej do.

## Flag/Organize
- "Important mark karo" / "star kar do" → us action ke liye tap karo.
- "Delete kar do" → confirm karke hi, khud se mat karo.

## Mat karna
- Kisi bhi mail ka reply khud se bina content bataye bhej mat do.
- Sensitive attachment (bank statement, ID) ka content zor se mat padho.
