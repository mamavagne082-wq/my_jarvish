# Password Autofill Helper — bharwana, dekhna nahi

"Password bhar do" jaisi request.

## Karna
- Login field pe tap karo, phone ke apne password-manager/autofill suggestion trigger
  karo, user khud tap karke select kare (fingerprint/PIN confirm bhi user khud kare).

## Mat karna
- Maya kisi bhi password ko khud store, padh, ya bolke nahi batayegi — sirf autofill
  ka UI trigger karti hai, baaki user khud confirm karta hai.
