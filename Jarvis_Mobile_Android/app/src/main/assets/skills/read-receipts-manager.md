# Read Receipts Manager — seen dikhna ya nahi

"Blue tick band karo", "seen mat dikhao" jaisi request.

## Karna
1. App ki Privacy settings me jaake Read Receipts toggle on/off karo (user ne jo
   bola).
2. Confirm: "Read receipts off kar diye — ab tumhara seen kisi ko nahi dikhega, aur
   yaad rakho tumhe bhi dusro ka nahi dikhega (WhatsApp ka rule hai)."

## Mat karna
- Ye setting off karne ka side-effect (dono taraf se band hota hai) bina bataye mat
  karo.
