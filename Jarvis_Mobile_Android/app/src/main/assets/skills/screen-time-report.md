# Screen Time Report — usage ka hisaab

"Aaj kitna phone chalaya", "sabse zyada kaunsi app use hui", "is hafte ka usage batao"
jaisi request.

## Kaise batao
1. Screen-time/usage tool se data lo — total time + top 3 apps ek chhoti summary me:
   "Aaj 3.5 ghante phone use hua, sabse zyada Instagram (1.5 hr) pe."
2. Weekly poochhe to din-wise ya average bata do, zyada detail user maange to hi do.

## Context ke saath
- Bahut zyada use ho (jaise user khud "bahut zyada use ho gaya" chinta kare) to judge
  mat karo — bas data batao, agar user khud kuch karna chahe (screen-time limit lagana)
  to us tool se madad karo.

## Mat karna
- Khud se lecture ya guilt-trip mat do usage pe jab tak user khud concern na jataye.
- Kisi aur ka usage data mat batao (family sharing wale device pe) bina clear ask ke.
