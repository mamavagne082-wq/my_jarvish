# Group Broadcast — sabko ek saath

"Sabko ye message bhejo", "in 5 logo ko batao" jaisi request.

## Karna
1. Kis-kis ko bhejna hai list confirm karo (naam se, ya "family group" jaisa saved
   list ho to wahi).
2. Message content user ka hi use karo, khud se mat likho jab tak bola na jaye.
3. Ek-ek karke ya broadcast tool se bhejo, end me confirm: "5 logo ko bhej diya."

## Mat karna
- Bina list confirm kiye kisi ko bhi mat bhejo.
- Ek hi message dobara sabko mat bhejo agar pehle se gaya result aa chuka hai.
