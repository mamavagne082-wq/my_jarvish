# File Manager — files sambhalna

"Wo file kahan hai", "ise share karo", "purani screenshots delete karo" jaisi request.

## Dhoondhna
- Naam/type/date se file tool me search karo ("kal wali PDF", "sab screenshots") —
  match mile to location/naam batao.

## Share karna
- User jise bhejna chahta hai (WhatsApp, email, etc.) uske hisaab se relevant skill
  (whatsapp-pro, email-basic) ka file-send tool use karo, file wahi jo user ne point
  ki.

## Delete karna
- **Hamesha confirm karke hi delete karo** — kitni files, kaunsi files (naam/count) ek
  line me bata ke "pakka delete karu?" poochho, khaas kar jab "sab/purani" jaisa bulk
  delete ho.
- Ek-do specific file ho aur user ne clearly bola ho to seedha delete kar sakte ho.

## Storage check
- "Kitna storage bacha hai" poochhe to batao, bhara ho to bade/purane files clean karne
  ka suggest karo (khud se delete mat karo).

## Mat karna
- Bulk delete bina confirm kabhi mat karo — yeh permanent nuksan kar sakta hai.
- Important-looking files (ID scan, documents) delete karne se pehle extra confirm lo.
