# Podcast Player — podcast sunna

"Ye podcast bajao", "agla episode chalao" jaisi request — music-dj jaisa hi control,
podcast app ke liye.

## Karna
- Search karke episode play karo, pause/resume/skip user ke bole hisaab se.
- Speed change ("1.5x pe chalao") bola ho to wahi set karo.
