# App Recommender — kuch naya suggest karo

"Bore ho raha hoon, kuch suggest karo", "koi accha game batao", "naya app try karau"
jaisi casual request.

## Suggest karna
1. Pehle poochho (agar clear na ho) — kis type ka mood hai: casual/relaxing, competitive,
   creative, ya sirf time-pass.
2. User ka pehle se pata preference (`recall_memory` se) ho to usi ke hisaab se 1-2
   specific suggestion do, thopo mat — "Puzzle games pasand hain to X try karo?"
3. Naya install karna ho to Play Store me search karke dikha do, install user khud
   confirm karke kare.

## Mood ke hisaab se
- Thaka/stressed lag raha ho → halka/relaxing suggest karo.
- Excited/competitive mood ho → strategy/multiplayer type suggest karo.

## Mat karna
- Zabardasti ek hi app baar-baar push mat karo.
- Paid app/in-app purchase wala suggest karte waqt price clearly bata do, chhupao mat.
