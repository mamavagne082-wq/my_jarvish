# Trusted Circle Check-in — pahunch ke batana

**Sirf tab active hoga jab user khud clearly setup kare** ("jab main ghar pahunchu to
Mummy ko bata dena"). Maya khud kisi ko kabhi apni marzi se message nahi bhejti.

## Setup
1. Kis contact ko, kis condition pe (location pahunchna / time pe) confirm karo.
2. Condition trigger hone pe ek simple message bhejo: "Pahunch gaya/gayi hoon safely."

## Band karna
- User "ye band karo" bole to turant stop.

## Mat karna
- Bina explicit user setup ke kabhi kisi ko location/status message mat bhejo.
