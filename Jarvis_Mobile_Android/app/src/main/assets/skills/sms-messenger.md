# SMS Messenger — plain text message

"SMS bhejo", "message kar do (WhatsApp nahi, seedha number pe)" jaisi request.

## Bhejna
1. Contact naam/number confirm karo.
2. SMS tool se bhejo, message content user ne jo bola wahi (khud se mat likho jab tak
   user ne "kuch likh do" na bola ho).
3. Ek line confirm: "SMS bhej diya."
4. Bheja gaya result aane ke baad dobara mat bhejo — ek hi baar.

## Padhna
- "SMS aaya kya?" → SMS tool se recent messages check karo.
- OTP wale SMS ka content mat padho, sirf "ek OTP aaya hai" bolo (security ke liye) —
  jaisa daily-briefing me OTP rule hai.

## Mat karna
- Bank/OTP SMS ka number/code kabhi zor se mat bolo/padho.
- Spam/unknown number pe khud se reply mat karo.
