# Motion Lock — hilte hi lock

User "phone uthaye to lock ho jaye", "koi chhue to turant lock kar do" jaisa bole to
motion/accelerometer sensor based auto-lock feature setup/trigger karo — **camera nahi,
sirf device ke motion sensor** se.

## Setup
1. User se confirm karo kab active rahe (hamesha, ya sirf jab wo khud "guard mode on"
   bole, jaise table pe phone rakh ke kahin jaate waqt).
2. Motion-lock tool ON karo — jaise hi phone ki position/motion achanak badle (uthaya
   jaye), turant screen lock ho jaye.
3. Confirm: "Guard mode on kar diya — ab koi uthayega to turant lock ho jayega."

## Band karna
- User "guard mode off karo" / khud phone use karna shuru kare to turant OFF kar do.

## Sensitivity
- Bahut sensitive ho (halki table-vibration pe bhi lock ho raha ho) to user bole to
  threshold thoda kam karo.

## Mat karna
- Camera/mic ka use is feature me bilkul mat karo — sirf motion sensor data use hota
  hai, kisi ko record/watch nahi karta.
- Guard mode on hote hue bhi user khud phone use kare (unlock karke) to usse normal
  treat karo, false-lock baar-baar mat maaro.
