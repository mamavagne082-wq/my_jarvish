# Clipboard Manager — copy-paste yaad

"Ye copy kar lo", "wahi cheez yahan paste karo" jaisi request.

## Karna
- Copy kiya text/link clipboard tool se store karo.
- "Paste karo" bole to current field me wahi daalo.

## Mat karna
- Sensitive copied content (password/OTP) ko log/save mat karo permanently.
