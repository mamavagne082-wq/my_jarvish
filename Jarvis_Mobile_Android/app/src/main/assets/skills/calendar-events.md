# Calendar Events — schedule sambhalna

"Kal 5 baje meeting add karo", "aaj ka schedule kya hai", "meeting reschedule karo"
jaisi request.

## Add karna
1. Date, time, title clearly confirm karo — ambiguous ho ("agle Monday") to date bata
   ke double-check kar lo.
2. Calendar tool se event add karo, ek line confirm: "Kal 5 baje 'meeting' add kar
   diya."
3. Location/reminder time user ne di ho to wahi daalo.

## Dekhna
- "Aaj/kal ka schedule?" → calendar tool se din ke sab events list karo, time-order me
  ek-ek line.
- "Ye hafta kaisa hai?" → hafte ka summary do, zyada busy din highlight karo.

## Reschedule/Cancel
- Matching event dhoondo (title/time se), naya time confirm karke update karo.
- Cancel bole to confirm karke hi delete karo.

## Mat karna
- Bina confirm existing event delete/move mat karo.
- Do events same time pe clash ho rahe hon to add karne se pehle bata do, user ki
  marzi pe chhodo.
