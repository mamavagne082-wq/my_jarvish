# Contacts Manager — number sambhalna

"Ye number save kar lo", "Amit ka number kya hai", "contact edit karo" jaisi request.

## Save karna
1. Naam + number confirm karo (user ne dono bole ho ya sirf number bola ho aur naam
   poochhna pade).
2. Contacts tool se save karo, ek line confirm: "Amit ka number save kar diya."
3. Same naam ka contact already ho to poochho — naya banao ya existing update karo.

## Dhoondhna
- Naam se poochha jaye → contacts tool se number nikaal ke batao.
- Number se poochha jaye ("ye kiska number hai") → reverse lookup karke naam batao,
  na mile to seedha bata do "saved nahi hai".

## Edit/Delete
- "Iska number badal do" → existing contact update karo, naya duplicate mat banao.
- "Delete kar do" → confirm karke hi delete karo, khud se kabhi mat karo.

## Mat karna
- Bina confirm kisi bhi contact ko delete/overwrite mat karo.
- Contact ka number kisi teesre ko bina user bole share mat karo.
