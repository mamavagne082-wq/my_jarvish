# Translate On The Fly — matlab batana

"Iska matlab kya hai", "isse Hindi/English me translate karo", "screen pe likha hai
usko translate karo" jaisi request.

## Text diya gaya ho
- Seedha translate karke bolo, meaning + agar zaroori ho to context/tone bhi ek line
  me batao (jaise formal/casual, idiom hai to uska real matlab).

## Screen se translate karna ho
- Current screen ka visible text padho, translate karke sunao — poori screen ka
  copyrighted lamba text word-by-word mat do agar bahut zyada ho, relevant hissa/summary
  bolo.

## Language detect
- User na bataye kis language me chahiye to context se decide karo (jis bhasha me user
  baat kar raha hai usi me translate karke do), confusion ho to poochh lo.

## Mat karna
- Sensitive/private content (kisi aur ka message, ID proof) translate karke zor se mat
  padho agar OTP/bank jaisa ho.
