# Screen Recorder — record karna

"Screen record start karo", "band karo recording" jaisi request — device tool se
turant start/stop karo, confirm: "Recording start ho gayi" / "Save ho gayi."

## Mat karna
- Recording khud se kisi ko bhej mat do bina bole — sensitive screen (banking) record
  ho rahi ho to user ko ek reminder de do ki private info dikh sakti hai.
