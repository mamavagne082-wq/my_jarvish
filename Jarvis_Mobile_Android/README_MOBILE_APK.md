# Jarvis AI Mobile APK Companion (মোবাইল এপিকে নির্দেশিকা)

এই প্রজেক্টটি জারভিস এআই অ্যাসিস্ট্যান্টের একটি পূর্ণাঙ্গ **অ্যান্ড্রয়েড কম্প্যানিয়ন অ্যাপ (Android Companion APK)**। এটি পিসির মতো সেম টু সেম ইন্টারফেস, এপিআই কি সেটিংস এবং পাওয়ারফুল কন্ট্রোল নিয়ে তৈরি করা হয়েছে।

---

## 🌟 মূল সুবিধাসমূহ (Key Features)

1. **পিসির মতো সেম টু সেম ইন্টারফেস (Cyberpunk HUD Web Interface):**
   - পিসিতে যে আকর্ষণীয় সাইবারপাঙ্ক ব্ল্যাক ও সায়ান থিম, ৩ডি ইন্টারেক্টিভ অরভ (3D Holographic Canvas Orb) এবং রিয়েল-টাইম অডিও স্পেকট্রাম ভিজ্যুয়ালাইজার রয়েছে—মোবাইলের ভেতরেও ঠিক একই ইন্টারফেস লোড হবে।
   - আর কোনো সাধারণ "24/7" ব্ল্যাক বক্স নয়! এখন পূর্ণাঙ্গ অ্যাপ ড্যাশবোর্ড, লাইভ ট্রান্সক্রিপশন চ্যাট হিস্ট্রি এবং বটম নেভিগেশন বার পাবেন।

2. **সম্পূর্ণ এপিআই কি সেটিংস কনফিগারেশন (Settings & API Keys Tab):**
   - পিসিতে যেমন সব ধরনের এপিআই কি বসানোর অপশন রয়েছে, মোবাইলেও **Settings** ট্যাবে গিয়ে সরাসরি মোবাইল থেকেই বসাতে ও পরিবর্তন করতে পারবেন:
     - **Google Gemini API Key**
     - **OpenAI API Key**
     - **LiveKit Cloud URL, LiveKit API Key & API Secret**
     - **Mem0 Long-term Memory Key**
     - **Google Search Key & Search Engine ID (CX)**
     - **OpenWeather API Key**
     - **Xiaomi Mimo API Key**
     - **ElevenLabs Voice API Key & Voice ID**
     - **User Name & Assistant Name**
   - **"SAVE ALL SETTINGS"** বাটনে ট্যাপ করলেই স্বয়ংক্রিয়ভাবে সেটিংস সেভ হয়ে নতুন এপিআই কি দিয়ে ইঞ্জিন চালু হয়ে যাবে।

3. **মোবাইল বুট অটো-স্টার্ট (`BOOT_COMPLETED`):**
   - মোবাইল ফোন বন্ধ হয়ে অন হলে বা রিস্টার্ট হলেও জারভিস স্বয়ংক্রিয়ভাবে ব্যাকগ্রাউন্ডে চালু থাকবে।
   - বারবার অ্যাপে ঢোকার কোনো প্রয়োজন নেই।

4. **২৪/৭ নিরবচ্ছিন্ন ভয়েস সার্ভিস (Foreground Service) ও ওয়েক ওয়ার্ড:**
   - মোবাইল ব্যাকগ্রাউন্ডে থাকলেও বা ফোন লক থাকলেও ব্যাকগ্রাউন্ডে মাইক ও স্পিকার সক্রিয় থাকবে।
   - যেকোনো সময় **"Hey Jarvis"** বা **"হে জারভিস"** বলা মাত্রই অ্যাপের UI ইন্টারফেস স্বয়ংক্রিয়ভাবে স্ক্রিনের সামনে পপ-আপ হয়ে কথা বলা শুরু করবে।

5. **স্বয়ংক্রিয় ব্যাকগ্রাউন্ড মিনিমাইজ (২০-৩০ সেকেন্ড অটো-হাইড):**
   - আপনার সাথে কথা বলা শেষ হলে অথবা ২০ থেকে ৩০ সেকেন্ড (ডিফল্ট ২৫ সেকেন্ড) কোনো কথা না বললে UI ইন্টারফেস স্বয়ংক্রিয়ভাবে মিনিমাইজ হয়ে ব্যাকগ্রাউন্ডে চলে যাবে (ঠিক পিসির মতো)।
   - আবার যখনই **"Hey Jarvis"** বলবেন বা মাইক বাটনে ট্যাপ করবেন, সাথে সাথে আবার UI সামনে চলে আসবে!

6. **ভয়েস দিয়ে ফোন কল ও ডায়ালপ্যাড (SIM 1 কল):**
   - **নাম দিয়ে সরাসরি কল:** "রহিমকে কল দাও", "আম্মুকে কল দাও" বললে কন্টাক্ট থেকে নাম্বার বের করে স্বয়ংক্রিয়ভাবে কল দেবে।
   - **১ সিম দিয়ে কল:** "নাম্বারটা বের করে ওয়ান সিম দিয়ে কল দাও" বা "কল দাও ওয়ান সিম দিয়ে"।
   - **ডায়ালপ্যাড সহ কল:** "ডায়াল প্যাড ওপেন করে ওয়ান সিম দিয়ে কল দাও"।

7. **হোয়াটসঅ্যাপ ও ফেসবুক মেসেঞ্জার অটোমেশন:**
   - **হোয়াটসঅ্যাপে মেসেজ:** "হোয়াটসঅ্যাপে এই নামটা খুঁজে বের করে হাই পাঠাও" বা "একটা মেসেজ দাও"।
   - **মেসেঞ্জারে মেসেজ:** "ফেসবুকে বা মেসেঞ্জারে এই নাম যে আছে তাকে একটা মেসেজ দাও", "ওকে মেসেজ দাও"।

8. **পিসির মতো সেম টু সেম মোবাইল নিয়ন্ত্রণ (`AccessibilityService`):**
   - **মোবাইল লক করা:** "মোবাইল লক করে দাও" বললেই সাথে সাথে মোবাইল স্ক্রিন লক হয়ে যাবে (`GLOBAL_ACTION_LOCK_SCREEN`)।
   - **ইউটিউব নিয়ন্ত্রণ:** "ইউটিউবে এই গান সার্চ করো" বললেই স্বয়ংক্রিয়ভাবে ইউটিউব অ্যাপ ওপেন হয়ে সেই গান প্লে হবে।
   - **যেকোনো অ্যাপ ওপেন:** "হোয়াটসঅ্যাপ ওপেন করো", "ফেসবুক ওপেন করো", "ক্যামেরা খোলো"।
   - **সার্ভে অটোমেশন (Survey Automation):** মোবাইলের স্ক্রিনে সার্ভের অপশন এবং নেক্সট বাটনে স্বয়ংক্রিয়ভাবে ট্যাপ বা ক্লিক করবে।
   - **সাউন্ড ও ভলিউম:** ভলিউম বাড়ানো বা কমানো।

## 📱 মোবাইলে একবার সেটআপ করার ধাপসমূহ

অ্যাপটি মোবাইলে ইনস্টল করার পর মাত্র **একবার** ওপেন করে নিচের ৩টি পারমিশন অন করে দিন:

1. **Microphone Permission:** ভয়েস কমান্ড শোনার জন্য মাইক্রোফোন অ্যালাউ করুন।
2. **Enable Accessibility Permission:**
   - অ্যাপের Settings বাটন থেকে **Accessibility Service**-এ ট্যাপ করে **Jarvis AI Assistant** অন করে দিন।
3. **Allow 24/7 Background Run:**
   - **Battery Optimization Whitelist**-এ ট্যাপ করে Unrestricted করে দিন যাতে অ্যান্ড্রয়েড ওএস ব্যাকগ্রাউন্ডে অ্যাপ বন্ধ না করে।
