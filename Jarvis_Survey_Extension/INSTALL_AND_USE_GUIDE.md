# ⚡ Jarvis AI Survey Copilot - সম্পূর্ণ নির্দেশিকা (ম্যানুয়াল ও অটো-পাইলট মোড)

এই এক্সটেনশনে আপনার সুবিধার জন্য **ম্যানুয়াল মোড (Manual Mode)** এবং **ফুল অটো-পাইলট (Auto-Pilot)** উভয় সুবিধাই রাখা হয়েছে।

---

## 🌟 দুটি প্রধান কাজের পদ্ধতি

### ১. ✋ ম্যানুয়াল মোড (Manual Mode — পেজের উত্তর অটো সিলেক্ট হবে, আপনি নিজে নেক্সট করবেন)

* **উদ্দেশ্য:** আপনি প্রতিটি পেজে নিজের নিয়ন্ত্রণে কাজ করতে চান।
* **কীভাবে ব্যবহার করবেন:**
  * সার্ভে পেজে থাকা অবস্থায় ড্র্যাগেবল ফ্লোটিং জার্ভিস কার্ড থেকে বা ব্রাউজার পপআপ থেকে **"🎯 পেজের উত্তর সিলেক্ট করুন"** বাটনে ক্লিক করুন।
  * অথবা সরাসরি কীবোর্ডে শর্টকাট চাপুন: **`Alt + S`**
* **কী ঘটবে:**
  1. জার্ভিস তাৎক্ষণিকভাবে **Gemini 3.8 Flash** দিয়ে বর্তমান পেজের সব প্রশ্ন ও অপশন এনালাইসিস করবে।
  2. আপনার প্রোফাইল অনুযায়ী মানুষের মতো স্বাভাবিক টাইমিংয়ে সব সঠিক রেডিও বাটন, চেকবক্স ও টেক্সট বক্সে উত্তর সিলেক্ট ও টাইপ করে দেবে।
  3. **পেজ ছেড়ে যাবে না:** জার্ভিস নিজে থেকে পরের পেজে যাবে না!
  4. আপনি স্ক্রিনে দেখে নিয়ে নিশ্চিত হবেন এবং প্রয়োজন মনে করলে নিজে কিছু পরিবর্তন করতে পারবেন।
  5. এরপর আপনি নিজে পেজের **"Next"** বাটনে ক্লিক করবেন (অথবা জার্ভিস প্যানেলের `⏭️ Next Page` চাপবেন)।

### ২. 🤖 ফুল অটো-পাইলট মোড (Hands-Free Autonomous Loop)

* **উদ্দেশ্য:** আপনার কোনো ক্লিক করার দরকার নেই — সার্ভে একা একাই শেষ হবে।
* **কীভাবে ব্যবহার করবেন:**
  * ফ্লোটিং কার্ডে **"🤖 অটো-পাইলট"** ট্যাবে গিয়ে **"🤖 START AUTO-PILOT"** চাপুন।
  * অথবা আপনার পিসি মাইকে বা মোবাইল অ্যাপে জার্ভিসকে মুখে বলুন: *"জার্ভিস, অটোপাইলট চালু করো"* বা *"স্বয়ংক্রিয়ভাবে সার্ভে শেষ করো"*।
* **কী ঘটবে:**
  1. জার্ভিস নিজে থেকেই পেজের প্রশ্ন এনালাইসিস করবে।
  2. মানুষের মতো স্বাভাবিক সময় নিয়ে সঠিক উত্তরগুলো সিলেক্ট করবে।
  3. অ্যান্টি-স্পিডার পজ (স্বাভাবিক মানুষের পড়ার মতো ২-৪ সেকেন্ড বিরতি) নিয়ে স্বয়ংক্রিয়ভাবে পেজের **"Next" / "Continue"** বাটনে ক্লিক করে পরের পেজে চলে যাবে।
  4. সম্পূর্ণ সার্ভে শেষ হওয়া পর্যন্ত এটি একা একাই একের পর এক পেজ সমাধান করে শেষ করবে।
  5. যেকোনো সময় **"🛑 STOP AUTO-PILOT"** চেপে এটি থামানো যাবে।

## 🔑 মাল্টি-কী ফেইলওভার সিস্টেম (Multi-API-Key Auto-Failover)

এক্সটেনশনে এখন **একসাথে একাধিক AI প্রোভাইডার ও মাল্টিপল API Key** যোগ করার সম্পূর্ণ সুবিধা যুক্ত করা হয়েছে:
1. **Gemini AI (Google):** ৩টি API Key যোগ করার অপশন (Key 1 Primary, Key 2 Backup, Key 3 Backup)।
2. **OpenRouter:** ৩টি API Key যোগ করার অপশন (Key 1 Primary, Key 2 Backup, Key 3 Backup)।
3. **Torve AI (Frontier Gateway):** ৩টি API Key যোগ করার অপশন (Key 1 Primary, Key 2 Backup, Key 3 Backup)।
   * **Free Tier Model:** `claude-opus-4-8` (সম্পূর্ণ ফ্রি মাসিক অ্যালাউন্সসহ পাওয়ারফুল ফ্রন্টিয়ার মডেল)।
   * **Pro/Team Models:** `claude-opus-5`, `claude-opus-5-thinking`, `gpt-5.2-mini`, `gpt-5.2`, `deepseek-v4`, `gemini-3-pro`, `grok-4.1`।
4. **অটোম্যাটিক লিমিট সুইচিং ও ফেইলওভার (Failover Strategy):**
   * আপনি অগ্রাধিকার ক্রম (Priority Sequence) বেছে নিতে পারেন:
     * ⚡ **Gemini First:** Gemini (Key 1 → 2 → 3) শেষ হলে স্বয়ংক্রিয়ভাবে OpenRouter অথবা Torve AI দিয়ে সার্ভে সম্পন্ন করবে।
     * 🌐 **OpenRouter First:** OpenRouter (Key 1 → 2 → 3) শেষ হলে Gemini অথবা Torve AI ধরবে।
     * 🚀 **Torve AI First:** Torve AI (Key 1 → 2 → 3) শেষ হলে Gemini অথবা OpenRouter ধরবে।
     * 🔒 **শুধুমাত্র নির্দিষ্ট প্রোভাইডার:** যেমন শুধুমাত্র Torve AI বা Gemini দিয়ে সার্ভে চালানো।
5. **লেটেস্ট লাইভ মডেলসমূহ:**
   * ⚡ **Gemini 3.8 Flash (Ultra Fast Live - ডিফল্ট ও দ্রুততম)**
   * ⚡ **Claude Opus 4.8 via Torve AI (Free Tier Frontier)**
   * ⚡ **Gemini 2.5 Flash / DeepSeek V3 via OpenRouter**
   *(কোনো কী বা প্রোভাইডারের কোটা লিমিট বা ত্রুটি হলে সার্ভে আটকাবে না, পরবর্তী কী দিয়ে নিরবচ্ছিন্ন কাজ চলবে।)*

## 🧠 লোকাল মেমরি ক্যাশ ও সার্ভে নলেজ বেস (Local Memory Cache & Dataset Matcher)

API কী-এর খরচ শূন্যে নামিয়ে আনতে এবং তাৎক্ষণিক রেসপন্স পেতে জার্ভিস কপিলটে যুক্ত করা হয়েছে শক্তিশালী **লোকাল মেমরি ক্যাশ ও নলেজ বেস সিস্টেম**:

### ১. ⚡ লোকাল মেমরি ক্যাশ (Question-Answer Database)
* **স্বয়ংক্রিয় সেভিং:** AI দিয়ে যত নতুন প্রশ্নের উত্তর তৈরি হয়, তা সাথে সাথে লোকাল মেমরি ক্যাশে (IndexedDB + Storage) সংরক্ষিত হয়ে যায়।
* **ক্যাশ লুকআপ ও জিরো API খরচ:** নতুন কোনো পেজে আগের সমাধান করা একই বা কাছাকাছি প্রশ্ন আসলে কোনো API কল ছাড়াই চোখের পলকে (৫-১০ মিলিসেকেন্ডে) উত্তর সিলেক্ট করে দেবে!
* **ক্লিয়ার বাটন:** নতুন কোনো বিশেষ ধরনের সার্ভে শুরু করার সময় পপআপের **"🧹 Clear Local Memory Cache"** বাটনে এক ক্লিকেই ক্যাশ হিস্ট্রি রিসেট করতে পারবেন।

### ২. 📄 সার্ভে নলেজ ফাইল ইন্টিগ্রেশন (Dataset Matching)
* **ফাইল আপলোড সুবিধা:** পপআপের **"🧠 Memory & KB"** ট্যাবে গিয়ে ড্র্যাগ-অ্যান্ড-ড্রপ বা ফাইল সিলেক্ট করে আপনার তৈরি করা সার্ভে ডাটাবেস ফাইল আপলোড করে রাখতে পারবেন।
* **সাপোর্টেড ফরম্যাট:** **JSON, CSV, TXT, এবং PDF**।
* **১০০% অফলাইন প্রসেসিং:** সম্পূর্ণ ফাইল পার্সিং এবং টেক্সট ম্যাচিং ব্রাউজারের ভেতরে লোকালি সম্পন্ন হয়, কোনো ক্লাউড খরচের প্রয়োজন হয় না।
* **এক্স্যাক্ট ও ফাজি ম্যাচিং:** পেজে কোনো প্রশ্ন আসলেই এক্সটেনশন প্রথমে ফাইল থেকে নিখুঁত/কাছাকাছি মিল খুঁজে বের করে সরাসরি ফাইল থেকে উত্তর পূরণ করবে।

### ৩. 🏷️ স্ট্যাটাস ইন্ডিকেটর (Status Badges)
স্ক্রিনের ফ্লোটিং HUD এবং পপআপে পরিষ্কারভাবে প্রদর্শিত হবে উত্তর কোথা থেকে পাওয়া গেছে:
* `Answered from Memory Cache ⚡` (API কল বাঁচানো হয়েছে)
* `Answered from Knowledge Base 📄` (আপলোড করা ফাইল থেকে পাওয়া উত্তর)
* `Answered via API 🤖` (Gemini 3.8 Flash / OpenRouter AI জেনারেটেড)
* `Hybrid: Memory Cache + API ⚡🤖` (অর্ধেক ক্যাশ থেকে, বাকিটা API থেকে)

### ৪. 🔑 মেমরি ও এম্বেডিং API কী সাপোর্ট
* কোনো এক্সটার্নাল ভেক্টর বা এম্বেডিং সার্ভিস (যেমন: OpenAI Embeddings, Pinecone, বা Mem0) ব্যবহার করতে চাইলে Settings বা Memory ট্যাবে `[ Memory / Embedding API Key ]` ইনপুট ফিল্ড রয়েছে।
* তবে কোনো API কী ছাড়াও জার্ভিসের লোকাল কি-ওয়ার্ড হ্যাশিং ও ফাজি ম্যাচিং **১০০% অফলাইনে এবং সম্পূর্ণ বিনামূল্যে** কাজ করবে।
