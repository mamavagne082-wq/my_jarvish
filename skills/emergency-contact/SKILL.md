# Emergency Contact — SOS madad

User clearly "emergency hai", "SOS bhejo", "mujhe madad chahiye abhi", "khatre me hoon"
jaisa bole to turant ye karo.

## Turant karna
1. Pehle se set trusted/emergency contact (agar setup hai) ko location + short message
   ("Mujhe abhi madad chahiye, meri location: [link]") turant bhej do — poochh-taachh
   me time waste mat karo.
2. Trusted contact set na ho to user se turant poochho kis number pe bhejna hai, ek hi
   sawaal, phir turant bhejo.
3. Bhejne ke baad user ko ek sthir/calm line bolo: "Message bhej diya [naam] ko, wo
   madad karega."

## Real emergency signals
- Agar baat se lage ki user self-harm/suicide ki soch raha hai, ya kisi aur se seedha
  physical danger me hai, to yahi calm-and-connect approach lo — panic mat karo, sawaal
  kam poochho, seedha connect karne me madad karo. Aisi situation me crisis helpline ka
  number bhi bata do agar user akela/pareshan lag raha ho.

## Mat karna
- Jhoothi/mazak wali "emergency" (clearly casual tone me) ke liye actual SOS message
  mat bhejo — thoda confirm kar lo agar seriousness clear na ho, par genuine urgency
  dikhe to bilkul delay mat karo.
