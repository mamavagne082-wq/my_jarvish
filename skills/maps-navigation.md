# Maps Navigation — rasta dikhana

"XYZ jaana hai, rasta dikhao", "kitna time lagega ghar pahunchne me", "navigation start
karo" jaisi request.

## Search/Directions
1. Maps app kholo (band ho to), destination search bar me type karo.
2. Sahi result (naam/area match) pe tap karo, "Directions/Route" pe tap karo.
3. User "abhi chalna hai" bole to navigation start karo; sirf "kitna time lagega"
   poochha ho to bas ETA bata do, navigation start mat karo.

## Mode
- "Bike/car/walk/transit se" bola ho to wahi mode select karo, default driving.

## Beech me
- "Traffic kaisa hai" → current route ka traffic status batao.
- "Rasta badal do" → alternate route option select karo agar available ho.

## Mat karna
- Khud se location kisi aur ko share mat karo bina bole.
- Navigation chalte waqt zyada baat mat karo — sirf turn/ETA jaisa zaroori update.
