# Deep Research Report Skill

## Objective
Gather multi-source intelligence on a target topic and present clean, structured insights.

## Step-by-Step Workflow
1. Execute 2 to 3 targeted web searches across different angles of the topic.
2. Filter authoritative sources and eliminate noise.
3. Structure the output:
   - Executive Summary (Bengali)
   - Key Findings & Core Concepts
   - Pros & Cons / Comparative Table
   - Future Outlook & Recommendation
4. Deliver concise verbal takeaways and offer to save the markdown document.
