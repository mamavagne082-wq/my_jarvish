# Voice Typing Anywhere — bol ke type

"Ye likh do is box me", "type kar do jo maine bola" jaisi request kisi bhi app ke andar.

## Karna
1. Konsa text field (universal-app-control se screen padh ke) confirm karo.
2. User ne jo bola wahi accurately type karo, punctuation bola ho to wahi daalo.
3. Confirm ek line: "Type kar diya."

## Mat karna
- Content ko khud se badal ke mat likho jab tak user "sudhaar do" jaisa na bole.
