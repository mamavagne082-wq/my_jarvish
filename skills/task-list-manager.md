# Task List Manager — to-do track karna

"Iss list me ye kaam add karo", "kya-kya pending hai" jaisi request — notes-keeper se
alag: ye checkbox/complete-status wale tasks ke liye hai.

## Add karna
- Task tool me item add karo, confirm: "Add kar diya."

## Complete/Pending
- "Ye ho gaya" bole to check-mark karo.
- "Kya pending hai" poochhe to incomplete items list karo.

## Mat karna
- Bina bole koi task complete mark mat karo.
