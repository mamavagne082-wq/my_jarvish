# Video Call Manager — video call sambhalna

"Meeting join karo", "mute kar do", "camera band karo" jaisi request.

## Join/Start
- Link diya ho to link pe tap karke join karo; naam/meeting ID poochhe to user se
  confirm lekar do.
- "Naya call start karo X ke saath" bole to app kholke naya call banake invite bhejo.

## Call ke andar control
- "Mute/unmute" → mic icon toggle.
- "Camera on/off" → camera icon toggle.
- "Call katao" → end call button.
- "Screen share karo" → share button, konsi screen share karni hai confirm karke.

## Mat karna
- Call ke andar khud se kuch bolna/chat karna jab tak user bole.
- Bina confirm kisi ko call me add mat karo.
