# Voice Lock Command — bolte hi lock

User "lock kar do", "phone band kar do abhi", "lock!" jaisa kuch bhi bole — chahe
jaldi/panic wale tone me ho — to **bina extra sawaal poochhe turant** screen lock kar
do. Ye ek safety-critical command hai, delay nahi honi chahiye.

## Turant karna
1. Koi confirmation nahi — seedha lock tool call karo.
2. Lock hone ke baad hi ek chhoti line: "Lock kar diya."

## Alag scenarios
- Kisi aur ke haath me phone jaate dikhe/lage (jaise user bole "kisi ne le liya mera
  phone") aur wo "lock karo" bole to turant karo, ye discuss karne ka waqt nahi.

## Mat karna
- "Lock kar do" sunte hi kabhi bhi clarifying question mat poochho ("kaunsa lock?" jaisa)
  — command clear hai, turant execute karo.
