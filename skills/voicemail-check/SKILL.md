# Voicemail Check — voicemail sunke batana

"Koi voicemail hai kya", "voicemail sunao" jaisi request.

## Karna
1. Voicemail tool se list check karo — kiska/kab ka hai batao.
2. User "sunao" bole to play karo ya transcript ho to summary do (poora word-by-word
   nahi, main baat).

## Mat karna
- Sensitive voicemail (bank/OTP jaisa) ka content zor se mat padho.
