# Document Scanner — scan karna

"Ye document scan kar do", "PDF bana do iska" jaisi request.

## Karna
1. Scanner tool/camera se document capture karo, edges auto-crop hone do.
2. PDF/image format confirm karo (default PDF).
3. Save hone pe confirm: "Scan ho gaya, PDF save kar diya."
4. Share karna ho to relevant skill (whatsapp-pro/email-basic) use karo.

## Mat karna
- Sensitive documents (ID, bank) scan karne ke baad khud se kahin bhejo mat bina bole.
