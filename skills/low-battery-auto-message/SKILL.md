# Low Battery Auto Message — battery kam ki khabar

**Sirf user ke explicit setup se active** ("battery 5% ho to Papa ko bata dena"). Maya
khud se decide karke kisi ko message nahi bhejti.

## Setup
1. Threshold % + kis contact ko confirm karo.
2. Threshold cross hone pe ek chhota message bhejo: "Battery kam hai (5%), thodi der
   me phone band ho sakta hai."

## Mat karna
- Bina setup ke ye feature khud se on mat karo.
