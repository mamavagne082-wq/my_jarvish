# System Quick Toggle — bina Settings khole on/off

User "wifi on karo", "torch jala do", "bluetooth band karo", "DND laga do" jaisa kuch
bole to **Settings app kabhi mat kholo** — seedha quick-toggle/device control tool se
ek hi step me kar do. Settings me jaake tap-tap karna slow aur galti-prone hai jab
seedha tool available hai.

## Torch/Flashlight
- "Torch/flashlight/light jala do" → turant ON. "Bujha do/band karo" → turant OFF.
- Koi confirmation lambi nahi chahiye, bas "Torch on kar diya" jaisi ek line.

## WiFi
- ON karna ho to seedha kar do.
- **OFF karne se pehle ek baar socho** — tumhara khud ka connection bhi isi se chal
  sakta hai (phone-care rule). User clearly bole "wifi band karo" to hi karo, khud se
  proactively kabhi mat karo.

## Bluetooth
- User jo bole wahi karo (ON/OFF) — headphone/speaker connect karna ho to ON karke
  batao ki pairing list me se device khud connect karna padega agar naya hai.

## DND (Do Not Disturb) / Silent
- ON/OFF turant karo. study-focus skill session ke andar bhi yahi tool use hota hai.
- User "sirf important calls aane do" bole to DND ka "priority/exceptions" mode agar
  tool support kare, warna simple ON karke batao ki sab silent ho jayega.

## Airplane Mode
- **Sirf tab jab user CLEARLY bole** ("airplane mode on karo", "flight mode"). Khud se
  kabhi mat lagao (phone-care rule) — isse tumhara khud ka connection bhi kat jayega.
- ON karne se pehle ek chhota reminder: "Airplane mode on karne se calls/data band ho
  jayenge, karu?" — agar user pehle hi confirm kar chuka hai to dobara mat poochho.

## Hotspot
- ON karo jab bola jaye; ek line me warn kar do agar battery/data zyada use hoga
  ("Hotspot on kar diya, data thoda zyada use hoga").
- OFF turant karo jab bola jaye.

## State check
- Agar user poochhe "wifi on hai kya?" jaisa status question, pehle current state
  check karo tool se, phir batao — guess mat karo.
- Already jo state maangi gayi wahi hai (jaise already ON hai aur "on karo" bola) to
  dobara toggle mat karo, bas batao "pehle se on hai".

## Fail case
- Agar quick-toggle tool available na ho ya permission block ho, tabhi fallback me
  Settings > [relevant section] ka rasta pyaar se batao — pehli koshish hamesha
  direct tool hi honi chahiye.
