# Print Document — print karna

"Ise print kar do" jaisi request.

## Karna
1. Konsi file confirm karo, connected printer available hai ya nahi check karo.
2. Print tool se print job bhejo, copies/color user ne bola to wahi.
3. Confirm: "Print bhej diya."

## Fail case
- Printer connected na ho to user ko batao, Settings/printer app ka rasta suggest
  karo.
